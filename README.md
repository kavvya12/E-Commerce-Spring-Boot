# E-Commerce Spring Boot

A backend-focused E-Commerce application developed using Java and Spring Boot. The project provides REST APIs for managing users, products, categories, shopping carts, and other core e-commerce operations.

## 🚀 Features

- User management and authentication
- Product management
- Category management
- Shopping cart functionality
- RESTful API development
- MySQL database integration
- Spring Data JPA and Hibernate
- Exception handling
- Secure API configuration
- Maven-based project structure

## 🛠️ Technologies Used

- **Java**
- **Spring Boot**
- **Spring Data JPA**
- **Hibernate**
- **MySQL**
- **REST APIs**
- **Maven**
- **Git & GitHub**
